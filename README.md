# Stechgrow internship — dataset upload backend

This repository contains a simple Python/FastAPI implementation of the dataset-upload part of the Stechgrow pipeline.

It is responsible for receiving CSV, XLS, XLSX, and JSON files; validating them; converting valid data into a consistent JSON representation; and making uploaded datasets available to later analysis modules.

## Start here

All runnable backend code and full instructions are in [backend/README.md](backend/README.md).

## Current scope

- File upload and validation: included.
- CSV/XLS/XLSX/JSON ingestion: included.
- Local MVP storage and upload history: included.
