# Automated Exploratory Data Analysis (EDA) Dashboard

An interactive web-based dashboard that simplifies Exploratory Data Analysis (EDA) by allowing users to upload CSV datasets and automatically explore their data through statistical summaries, visualizations, and anomaly detection.

## Features

* **CSV Upload:** Upload datasets in CSV format.
* **Statistical Summary:** View important statistical measures such as mean, median, minimum, maximum, and standard deviation.
* **Missing Value Analysis:** Identify and visualize missing values in the dataset.
* **Correlation Heatmap:** Understand relationships between numerical columns.
* **Outlier Detection:** Identify potential anomalies using statistical methods.
* **Data Visualization:** Explore datasets through interactive charts.
* **Processing States:** Display loading, processing, error, and results states.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your system.

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd Product
```

Install the dependencies:

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### Build for Production

```bash
npm run build
```

## Project Purpose

The objective of this project is to make data exploration easier and faster by providing an organized interface for understanding datasets without manually performing every analysis step.
